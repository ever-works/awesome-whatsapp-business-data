## Overview

Baileys is a TypeScript and JavaScript WhatsApp Web API library for building WhatsApp bots and automation tools.

## Features

- WhatsApp Web API integration
- Send and receive messages
- Group management
- Media handling (images, documents, audio, video)
- Typing indicators and read receipts
- Contact and profile management
