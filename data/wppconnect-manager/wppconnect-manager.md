## Overview

WPPConnect Manager is a self-hosted WhatsApp REST API built on WPPConnect. It enables management of sessions, messages, media, contacts, groups and webhooks with Docker deployment and a web UI.

## Features

- WhatsApp REST API
- Session management
- Message, media, contact and group management
- Webhooks
- Docker deployment
- WPPConnect Manager UI

## Pricing

Free and open source.

## Deployment

Self-hosted.
