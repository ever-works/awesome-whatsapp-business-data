## Overview

Waxum is an MIT-licensed WhatsApp gateway written in Rust, distributed as a single binary with a REST API and webhooks for WhatsApp messaging and automation.

## Features

- WhatsApp gateway functionality
- REST API for message sending and receiving
- Webhooks for event notifications
- Single binary distribution
- WhatsApp messaging without WhatsApp Business API dependency
