## Overview

The WhatsApp Cloud API is Meta's official cloud-hosted API for the WhatsApp Business Platform, enabling businesses to communicate with customers on WhatsApp without self-hosting.

## Features

- Cloud-hosted WhatsApp messaging (no self-hosting required)
- Send and receive messages, media, and documents
- Message template management and approval
- Webhooks for message delivery and status updates
- Phone number management
- Integration with WhatsApp Business Platform

## Pricing

The API is free to use. Meta charges per conversation based on conversation-based pricing tiers (business-initiated and user-initiated conversations).

## Deployment

Cloud-hosted (managed by Meta).

## Integrations

Meta Business Suite, CRM platforms, and custom applications via REST API.
