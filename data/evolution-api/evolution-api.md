## Overview

Evolution API is an open-source WhatsApp integration API written in TypeScript. It enables self-hosted WhatsApp messaging and automation through a REST API.

## Features

- WhatsApp integration via REST API
- Session management
- Message sending and receiving
- Self-hosted deployment
- TypeScript-based
