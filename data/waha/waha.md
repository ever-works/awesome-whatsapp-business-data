## Overview

WAHA - WhatsApp HTTP API is a REST API for WhatsApp that can be configured in a click. It supports multiple engines including WEBJS (browser based), NOWEB (websocket nodejs), GOWS (websocket go), and WPP (browser).

## Features

- WhatsApp HTTP API (REST API)
- Multiple engine support: WEBJS, NOWEB, GOWS, WPP
- Browser-based and websocket options
- Session management
- Self-hosted deployment

## Pricing

Free and open source.

## Deployment

Self-hosted.
