## Overview

GOWA is a WhatsApp REST API built with Golang for efficient memory use. It supports UI, Multi Account, Webhooks, MCP, and Chatwoot integration.

## Features

- WhatsApp REST API
- Multi-account support
- Webhooks
- UI dashboard
- MCP and Chatwoot integration
- Self-hosted deployment

## Pricing

Free and open source.

## Deployment

Self-hosted.
