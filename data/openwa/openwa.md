## Overview

OpenWA (wa-automate-nodejs) is a WhatsApp automation framework for Node.js that enables chatbot creation and message automation through WhatsApp Web.

## Features

- WhatsApp automation via WhatsApp Web
- REST API for message sending and receiving
- Webhooks for event notifications
- Session management
- Chatbot building capabilities
- Media and contact handling

## Pricing

Free and open source.

## Deployment

Self-hosted.
